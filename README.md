# MIST 3.6.5 · 液态玻璃性能优化版

Chrome / Edge Manifest V3 新标签页扩展。保留 MIST 3.3.1 的布局与玻璃风格。

![MIST 雾林新标签页](docs/images/new-tab.png)

以雾林摄影为背景，提供液态玻璃搜索框、可编辑的快捷网站与收藏卡片，以及本地壁纸和影像外观设置。

![液态玻璃与壁纸设置](docs/images/glass-settings.png)

- 当前版本：`3.6.5`，无构建步骤或第三方 JavaScript 依赖。

## 安装
下载本仓库 ZIP 并解压。在 Edge 访问 `edge://extensions`，或在 Chrome 访问 `chrome://extensions` → 开启开发者模式 → 加载已解压的扩展程序 → 选中包含 `manifest.json` 的文件夹。安装后打开新标签页即可使用。

## 新功能
- 8 种影像预设：原片、电影、黑白、冷雾、旧胶片、午夜、纸本档案、柔光。
- 精细调色：对比度、饱和度、色温、雾感、暗角。
- 纹理：胶片、纸张、扫描线、漏光，支持强度调节。
- 可上传壁纸，所有调节非破坏性且保存在浏览器本地。
- 折射使用共享 WebGL2 画布与后台线程；没有第三方依赖。

## 数据保留
使用原有 `mist-tab-state-v1` 存储键。若要保留同一扩展 ID 与设置，将此文件夹内容覆盖安装目录后在扩展页点击重新加载；直接安装到新目录可能生成不同 ID，设置不会自动迁移。请先备份。


## 液态玻璃与缓慢漂移
搜索框和快捷按钮使用按 Outpace 校准的曲面折射：n=1.5、平滑圆角、边缘折射与方向性高光。收藏卡片使用按 Bubbbly 校准的六次幂透镜、内部放大与 9×9 背景柔化。旧版均匀描边与鼠标光斑已被移除。

保留强度、高光、色散滑块。所有玻璃共用一个 GPU 画布，按可见玻璃的局部范围绘制；开启缓慢漂移时，玻璃内的摄影层同步跟随主背景。文字和交互层保持独立，不参与背景位移。设置里的圆片使用同一套实时折射。

材质参考：[Outpace](https://glass.outpacestudios.com/) 与 [Bubbbly](https://www.bubbbly.com/app/github-glass-badge.html)。保留已校准的曲面折射、六次幂透镜、背景柔化顺序和高光公式。背景栅格、Outpace 位移贴图在一个 Worker 内生成；WebGL2 初始化、着色器与纹理上传、实际绘制由另一个 Worker 通过 OffscreenCanvas 完成。方向性细边仍使用 SVG 路径，不再使用逐块 SVG 位移滤镜。

## 性能策略
- 移除每块玻璃的整套背景副本，16 块玻璃共享背景纹理。
- 9×9 均值柔化分为横向、纵向各 9 次取样，保留相同核与取样半径。
- 强度拖动即时更新着色器参数；几何贴图在停止输入 100 毫秒后合并生成并缓存。
- 静止画面仅在内容或位置变化时重绘；缓慢漂移最多每秒重绘 60 次，后台标签页暂停。
- 后台绘制至多保留一个执行中帧和一个最新待绘制帧，避免消息堆积。
- WebGL2 不可用时显示原生磨砂回退；支持系统减少动态效果、减少透明度设置。

性能取决于显卡、浏览器和视口。帧回调间隔与实际显示帧率不同，不保证所有设备达到同一帧率。

## 更新后生效
覆盖文件后，在 Chrome / Edge 的扩展管理页重新加载 MIST，再打开新标签页。左上角显示 `ATELIER / V3.6.5` 表示已加载这一版。旧标签页仍可能保留旧脚本，需刷新或重新打开。
